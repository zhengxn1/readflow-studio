# ReadFlow Studio

ReadFlow Studio（读流工作室）是一套从 Obsidian 阅读知识库到可编辑剪映草稿的开源工作流。它负责整理书籍资料、生成文案与分镜、组织配图，并把用户提供的正文 MP3 和 SRT 编排成多轨剪映草稿。

当前主流程以用户提供的 SRT 为唯一时间真源，不依赖 Whisper，也不会强制渲染不可编辑的成片。

## 最终得到什么

- 一个按期保存的制作目录，包含素材清单、字幕、分镜、图片提示词和审核记录。
- 一个已经安装进本机剪映草稿库的可编辑草稿。
- 独立的视频、图片、旁白、BGM、音效、中英文字幕、书名和作者轨道。
- `3:4`、`9:16`、`4:3` 三种可选画幅，以及随画幅自动换算的排版位置。

## 每期需要提供

1. 书名，以及在 Obsidian 中可匹配的微信读书笔记。
2. 已确认的正文朗读 MP3。
3. 与正文音频对应、从 `00:00:00` 开始的中文 SRT；第一条必须是书名。
4. 与中文逐条对应的英文 SRT。英文文本会强制沿用中文时间线；明确不要英文字幕时可使用 `--no-english`。
5. 可选的画幅和分镜字幕数量，例如 `--aspect 3:4`、`--scene-cue-counts 5,6,5,5,5`。

如果 Obsidian 中暂时没有封面，可以使用 `--cover "/本地封面.jpg" --author "作者"` 提供已确认封面；网络查询和版权确认由 Agent 在准备命令前完成。

书籍封面优先读取 Obsidian 笔记的 `cover` 字段。每本书仍放在同一个 `episodes/` 根目录下，只为当期建立隔离文件夹，避免不同书籍的音频、字幕和配图互相覆盖。

## 标准流程

1. 根据 Obsidian 书籍资料、个人划线和笔记生成文案。
2. 在对话中确认文案；未确认前不生成配图和草稿。
3. 用户生成正文 MP3、中文 SRT；系统补齐逐条英文 SRT。
4. 执行准备命令，读取封面、校验字幕、计算片头偏移并生成 `storyboard.md`。
5. 每个分镜覆盖 5～10 条正文字幕，一镜一图；确认分镜后才生成图片。
6. 将图片保存为 `images/scene-001.png`、`scene-002.png`……
7. 生成剪映草稿，复制素材到草稿自己的 `assets/` 目录并重写路径。
8. 完全退出并重新打开剪映，检查草稿后手动导出最终视频。

完整规则见 [制作手册](docs/readflow-studio-playbook.md)。

发布或二次开发前，请按照 [GitHub 发布清单](docs/publish-checklist.md) 完成检查。

## 固定片头和音效时序

1. 片头 MOV 与“今天我们要分享的是”语音同步，不显示这句话的字幕，也不播放机械音效。
2. MOV 结束后播放快闪素材，并从快闪开始同步机械音效。
3. 快闪结束后显示符合视频比例的全画幅书籍封面，以“水滴遮罩”入场，同步播放完整水滴音效；原封面保持比例，空余区域用同封面的柔化背景适配，正文 MP3 与第一条书名字幕从此处开始。
4. 书名朗读结束后，第一句正文开始：切换第一张分镜图，缩小封面以“点开”动画进入，并同步播放 `正文开头音效.mp3`。
5. 书名和作者从书名朗读结束后持续到视频结束。

替换同名固定音效后重新生成草稿，即可使用新音效，不需要修改代码。

## 字幕和排版

- 中文、英文字幕是两个独立轨道；英文默认字号为 `5`，位于中文字幕下方。
- 英文字幕只使用自己的文本，开始和结束时间强制复制对应中文字幕，避免双语错位。
- 书名、作者、中英文字幕按画布高度比例定位：书名约 `49%`、作者约 `36%`、中文约 `-38%`、英文约 `-50%`。
- 切换 `3:4`、`9:16`、`4:3` 时自动重新计算位置，避免标题区和字幕区拥挤。
- 位置与字体可在 `templates/jianying-draft/layouts.json` 中统一调整。

## 配图规则

- 分镜数量由正文长度决定，不固定为7张，也不是每句话一张图。
- 每镜原则上覆盖5～10条字幕，只表达一种情绪或象征。
- 六种视觉风格轮换使用，同一期尽量至少出现4种。
- 画面以风景、空间、静物和象征隐喻为主；人物只允许远景、背影或剪影，面积不超过10%。
- 禁止真人近景、清晰五官、文字卡片、水印、机甲、战争、血腥和夸张史诗效果。
- 图片必须按目标画幅生成并保持比例，禁止拉伸。

准备阶段会生成 `generated/image-prompts.json`，它和 `storyboard.md` 一起作为配图依据。

## 第一次使用

```bash
npm run init
npm run capcut:setup
```

将 `config/workflow.example.json` 复制为 `.readflow.local.json`，填写：

- Obsidian 仓库和微信读书笔记目录。
- 固定片头、BGM、快闪素材和音效目录。
- CapCut Mate 本地服务参数。

然后启动草稿服务：

```bash
npm run capcut:start
```

## 准备一期视频

```bash
npm run workflow:prepare -- \
  --book "被讨厌的勇气" \
  --voice "/绝对路径/正文朗读.mp3" \
  --srt "/绝对路径/中文字幕.srt" \
  --srt-en "/绝对路径/英文字幕.srt" \
  --aspect "3:4" \
  --scene-cue-counts "5,6,5,5,5"
```

确认 `episodes/<项目名>/storyboard.md` 并补齐图片后，先执行干跑检查：

```bash
npm run workflow:draft -- --project "项目名" --dry-run
```

确认无误后安装到剪映：

```bash
npm run workflow:draft -- \
  --project "项目名" \
  --install-to-jianying \
  --jianying-dir "/剪映草稿库目录" \
  --draft-name "自定义草稿名称"
```

如果用户没有提供剪映草稿库目录，工作流必须主动询问，不能猜测或扫描私人目录。

## 隐私和开源

- `.readflow.local.json`、`.readflow-state.json`、`.env`、`.tools/` 和 `episodes/` 都不会提交。
- 公开仓库只保存代码、示例配置、模板参数和工作方法。
- 固定 BGM、音效、字体、封面和生成图片需要使用者自行确认授权。
- 本机旧版 Whisper/HyperFrames 文件可以继续保留用于历史项目，但已加入忽略规则，不属于 GitHub 发布内容。

项目代码和自有文档采用 [Apache-2.0](LICENSE)；第三方素材继续遵循各自许可。
