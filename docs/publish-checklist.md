# GitHub 发布清单

完成下一本书的完整测试后，再执行发布。

## 发布前必须完成

- [ ] 新书能够从 Obsidian 读取书名、作者和封面。
- [ ] 中文 SRT 第一条为书名，英文字幕与中文条数和时间一致。
- [ ] 每个分镜覆盖5～10条字幕，一镜一图。
- [ ] 片头、机械音效、水滴音效、正文开头音效时间正确。
- [ ] 三种画幅中至少实测本期选择的画幅。
- [ ] 剪映草稿能够打开，图片、音频和字幕都有权限。
- [ ] `npm run check` 通过。
- [ ] `npm run check:public` 通过。
- [ ] GitHub 远端是用户自己的 `readflow-studio` 仓库，不是原始参考仓库。

## 不进入 GitHub 的内容

- `.readflow.local.json`、`.env` 和本机状态。
- `episodes/` 中的书籍、音频、字幕、图片和草稿记录。
- `.tools/`、CapCut Mate 运行环境和剪映草稿。
- BGM、音效、片头 MOV、封面、生成图片等媒体文件。
- `.ai/` 和本地分析文件。
- 旧版 Whisper/HyperFrames 脚本和模板。

当前仓库来自参考项目的浅克隆。正式发布到新 GitHub 仓库时应使用干净的发布快照或清理旧历史，避免旧提交中的第三方媒体随历史一起上传。
