# 第三个模板：三分钟精读知识卡片规范

## 目标

从一本书的正文 MP3、原始 SRT、4:3 背景和分镜插画，一次生成可编辑的 1440×1080 剪映草稿。模板规则来自第三模板原始工作流代码，并以本规范中的用户修订为最终准则。

## 时间结构

1. 固定片头音频从 0 秒开始；画面使用打开的书，不提前显示正文插画。
2. 片头字幕只有一条：`3分钟精读一本书，今天我们读《书名》`。书名通过剪映字幕富文本关键词着色，不创建居中的独立大标题。
3. 第一条正文开始时，打开的书结束，第一张透明插画出现；后续插画按分镜时间切换。
4. 正文 MP3 从固定片头结束处开始，SRT 整体增加相同偏移。

## 画面与动画

- 画布：1440×1080，4:3。
- 背景：全程静态铺满。
- 打开的书：画面中央，淡入并做轻微呼吸运动。
- 正文插画：按文案生成扁平手绘人物情境插画，以人物动作、情绪和相关道具表达内容，不使用风景图、纯静物图或抽象氛围图；确认肢体与持物关系正确后，抠图为透明 RGBA 并置于画面中央。
- 所有前景画面的缩放关键帧统一为 80%→85%，不得使用 100%→106%。
- 入场动画只使用轻量渐显、上滑、放大或翻页，不改变 80%→85% 的缩放范围。
- 每个新素材必须保留原文件，修复版使用新文件名，避免破坏可追溯性。

## 四段导航和进度

- 固定文案：`书籍引入 / 内容介绍 / 解决问题 / 价值倡导`。
- 导航中心点：x=`-1108 / -414 / 287 / 1052`，y=`1000`。
- 四个导航分块从0秒持续显示到视频结束。
- 不使用灰色或珊瑚色进度条，不使用正文阶段的章节高亮。
- 三个分隔符位于相邻导航的中点 x=`-761 / -64 / 670`，同样从头显示到尾。
- 导航词只存在于导航轨，不得作为画面中央标题、独立重点词或字幕外总结再次出现。

## 字幕与关键词

- 开场字幕位置沿用原始代码的字幕区；书名关键词颜色为 `#FE8A80`。
- 正文每句 SRT 生成一条剪映字幕。
- 每句必须选择该句中真实存在的一段连续文字作为关键词；不得用句外总结词。
- 关键词写入剪映字幕的 `keyword`、`keyword_color`、`keyword_border_color` 和 `keyword_font_size` 字段，由剪映富文本样式完成局部高亮。
- 默认自动抽取关键词；若 `generated/caption-keywords.json` 存在，则用其中逐句配置覆盖。生成前会验证每个关键词确实属于原句，错误时直接停止，不生成半成品草稿。
- 不再创建“重点词”独立字幕轨。

## 书名、作者与署名

- 开场书名字号15，位置 x=`0`、y=`650`；作者位置 x=`330`、y=`400`。
- 正文阶段书名位置 x=`-1045`、y=`-785`；作者位置 x=`-1065`、y=`-940`。
- 开场与正文书名作者为两组独立时间段，不用一条常驻文字跨越全片。
- IP 昵称保留在右下，沿用原始代码位置 x=`582`，y=`-452`。

## 每本书的一次生成输入

必须提供：

- 正文 MP3；
- 第一条为书名的中文字幕 SRT；
- 4:3 背景；
- 打开书透明图；
- 与分镜一一对应的透明插画。

模板会自动完成片头拼接、SRT 偏移、逐句关键词、四段进度、80%→85% 动画、音频轨和剪映草稿安装。若需要人工精选关键词，只修改可选的 `generated/caption-keywords.json`，其余参数无需逐期调整。

## 生成前强制检查

- SRT 第一条与本期书名一致；
- 每个分镜文件存在且为透明 PNG；
- 每条关键词是字幕原句的连续子串；
- 四段导航坐标和数量正确，且从头显示到尾；
- 草稿中不存在进度条文字或珊瑚色章节覆盖层；
- 缩放起止值严格为 0.8 和 0.85；
- 新草稿名称不得与剪映草稿库已有目录重名。
