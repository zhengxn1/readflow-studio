# 唱片播放器模板：参考视频还原规范

参考视频规格：2560×1440、30fps、11.5秒。参考媒体属于本地素材，不随公开仓库上传。

## 锁定结构

- 成片比例为 16:9，模板画布为 1920×1080。
- 背景是深红色布光/颗粒氛围，不使用正文分镜大图轮播。
- 左侧播放器由等宽旋转大唱片、方形圆角封面窗、32%旋转彩色小播放器和圆形音符动画组成；播放器位置贯穿全片不变。
- 顶部左侧显示 `REC` 和红点。
- 书名固定在右上方，作者位于书名下方；正文字幕位于右侧中部，波形上方。
- 底部保留时间、进度线、移动圆点、波形和播放控制。

## 时间线

| 时间 | 画面 / 声音 |
| --- | --- |
| 0.00–2.77s | 使用“睡前读完一本书，今天我们读音频.mov”；左侧显示指定的 IP 形象图 |
| 0.10–1.55s | `睡前听完一本书` 模糊甩入、停留、淡出 |
| 1.65–7.05s | `今天我们读` 渐显；快闪期间保持，目标书名稳定后淡出 |
| 2.90–5.75s | 12 张书封只在左侧方形封面窗内快闪，单张约 0.24s |
| 5.75–6.10s | 目标书封与书名使用放大、模糊感甩入；啵音效同步 |
| 6.20s 起 | 正文旁白开始；书名、作者和目标封面持续显示 |
| 7.63s 起（示例） | 从 SRT 第 2 条开始显示正文字幕，避免书名重复 |

## 素材规则

- 快闪素材在进入模板前只统一中心裁切为 1024×1024，不预先裁圆角；片头 IP、快闪和目标书封都在剪映草稿内设置矩形遮罩圆角20。
- 原始快闪图应预处理为正方形，并通过 `.readflow.local.json` 的 `templates.cassettePlayer.flashDir` 指定。
- 每本书使用单独设计的 1024×1024 主题封面，不要求复刻出版物封面，但必须准确显示书名；默认路径为每期项目的 `images/cassette-square-cover.png`。
- 左侧层级从下到上锁定为：与封面边长相同的大唱片 → IP/快闪/目标书籍封面 → 32%彩色小播放器 → 圆形音符动画。
- 正方形封面本身不绘制边框；在剪映草稿中统一添加矩形遮罩，圆角参数20。
- 剪映坐标锁定：正方形快闪和封面 `x=-1200`；书名、作者及字幕 `x=800`。
- 字号锁定：右上书名 `10`，正文字幕 `5`。
- 大唱片和彩色小播放器各自使用独立旋转轨，约每5秒旋转一周；小播放器剪映参数为32%、`x=-660`、`y=120`。
- 左右底部波形均为15%，位置分别为 `(-1632,-918)` 与 `(1632,-918)`；计时卡为6%，位置 `(-1700,-820)`。
- 中央长波形放在右侧文字下方；左右小波形放在底部两端。进度条接近全宽，进度圆点从 `x=-1510` 移动到 `x=1545`。
- 底部播放控件、当前时间和总时长统一贴近参考图的黑色播放器区域。
- 播放器固定素材位置通过 `templates.cassettePlayer.materialsRoot` 配置。
- 片头IP通过 `templates.cassettePlayer.ipCover` 或 `--ip-cover` 指定。
- 片头音频通过 `templates.cassettePlayer.introAudio` 或 `--intro-audio` 指定。
- 正文文案、时间线继续从每期上传的 MP3/MOV 与 SRT 文件读取。
- 中文字幕SRT第一条必须是本期书名；缺失或不匹配时停止生成，并提醒用户在剪映字幕中补上书名后重新导出、上传。
- 剪映草稿仍安装到原有草稿库位置。
