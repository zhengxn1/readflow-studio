# 从选书到剪映草稿：用户总提示词

这段提示词用于让 Codex 从选书和文案开始组织整期视频，而不是要求用户预先准备好正文 MP3 和 SRT。

## 使用前只需填写

- 账号定位：例如个人成长、女性成长、心理学、商业认知；
- 目标观众：例如20～35岁职场女性；
- 本期主题：例如拖延、焦虑、亲密关系；
- 视频时长：默认3分钟；
- 使用模板：模板1、模板2或模板3；
- 可选书单：可以留空，由AI推荐；
- 可用资料：个人读书笔记、合法获得的摘录或书籍资料。

AI不得仅凭书名编造书中观点。没有可靠资料时，应先说明依据不足，并让用户补充读书笔记、摘录或允许查询的资料来源。

## 可直接复制的总提示词

```text
请使用 ReadFlow Studio 从选书开始，为我完成一期书单视频项目。

账号定位：【填写账号定位】
目标观众：【填写目标观众】
本期主题：【填写主题】
目标时长：【默认3分钟】
使用模板：【模板1 / 模板2 / 模板3】
候选书籍：【可以留空】
可用资料：【读书笔记、摘录或资料文件】

请按以下顺序执行：

一、选书

1. 根据账号定位、目标观众和本期主题选择适合短视频解读的书。
2. 如果我提供候选书单，从中选择最适合的一本；如果没有候选书单，给出3本候选书并从中选出最推荐的一本。
3. 选书时比较主题匹配度、受众需求、可提炼观点、短视频开头吸引力和内容可信度。
4. 输出选书理由和资料依据。不要根据书名猜测或编造书中观点。
5. 默认直接采用评分最高的一本继续制作；只有在资料不足或存在版权、书名、作者等实质性不确定时才暂停询问。

二、提炼内容

1. 阅读我提供的读书笔记、摘录和可靠资料。
2. 提炼一个核心问题、一个核心观点、2～3个支撑观点和一个可执行建议。
3. 所有观点必须能追溯到资料，不虚构作者原话，不拼接伪造金句。
4. 输出一份简短的选题卡，包含书名、作者、目标观众、核心问题、核心观点、观众看完能得到什么。

三、生成口播文案

1. 按目标时长生成适合自然朗读的中文口播稿。3分钟视频正文以约650～850个汉字为参考，并根据实际语速校准。
2. 文案结构为：
   - 开头钩子：用观众熟悉的问题或冲突引入；
   - 书籍引入：介绍书名、作者及它解决的问题；
   - 内容介绍：讲清核心观点和原因；
   - 解决问题：给出具体方法或行动步骤；
   - 价值倡导：用一句克制、有力量的结尾收束。
3. 文案使用短句和口语表达，不写论文式摘要，不堆砌金句，不夸大书籍效果。
4. 模板3的四个内容阶段对应“书籍引入 / 内容介绍 / 解决问题 / 价值倡导”。
5. 生成后自行检查事实、逻辑、重复内容、朗读节奏和预计时长，并直接修正。

四、生成配音稿与字幕

1. 输出最终口播稿和纯净配音稿。
2. 如果当前环境具备配音能力，生成正文MP3及与音频逐句对齐的中文字幕SRT。
3. 如果当前环境不具备配音能力，保存最终配音稿，并明确告诉我需要使用哪份文案生成MP3和SRT；不要伪造字幕时间。
4. SRT第一条按所选模板的要求处理书名，后续每条字幕保持自然语义完整。

五、生成分镜和AI图片

1. 每个分镜原则上覆盖5～10条字幕，一镜一图，图片必须对应当前分镜文案。
2. 模板1：根据每段正文生成对应分镜图片。
3. 模板2：根据整篇内容生成1024×1024主题书封和1920×1080背景图。
4. 模板3：沿用我上传的4:3背景模板；根据正文生成扁平手绘、知识科普风的人物情境插画。
5. 模板3不得生成风景图、纯静物图或抽象氛围图。通过人物动作、表情和相关道具表达文案；检查头部、手臂、手掌、手指数量、肢体连接和持物关系。
6. 模板3插画使用纯绿色背景生成，抠图为透明RGBA PNG后置于画面中央，同一期保持人物造型、线条和配色一致。

六、生成剪映草稿

1. 严格使用我选择的模板，不混入其他模板的素材、坐标或动画。
2. 先生成项目清单、分镜、AI素材清单和审核记录。
3. 素材齐全后运行草稿生成流程并安装到剪映草稿库。
4. 保留所有原始文件，不覆盖旧草稿；修复版使用新的文件名和草稿名。
5. 完成后运行项目测试和公开文件检查。

最后向我交付：

1. 选中的书及选择理由；
2. 选题卡；
3. 最终口播文案；
4. 配音稿、MP3和SRT状态；
5. 分镜数量及每镜对应内容；
6. AI图片生成清单；
7. 剪映草稿名称和安装位置；
8. 需要人工复查的项目。
```

## 重要说明

ReadFlow Studio 当前以真实正文 MP3 和逐句对齐的 SRT 作为剪映时间线。AI可以先完成选书、资料整理和文案；只有在当前环境具备配音能力时才能继续自动生成MP3和精确SRT。缺少配音能力时，用户需用最终配音稿生成MP3和SRT，再继续对应模板的草稿流程。
