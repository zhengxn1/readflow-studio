# 可选片头素材与独立配音设计

## 目标

为前 10 条视频建立一条简单、稳定、便于替换内容的制作流程：每期显式提供片头话术配音、书名配音、正文配音和正文字幕；固定素材目录中的片头视频、快闪图片、BGM 与音效均按实际存在情况使用，缺失时不阻断项目准备或剪映草稿生成。

本轮不建设通用时间线编辑器，也不自动扫描和猜测每期配音文件。待 10 条视频的数据验证完成后，再根据实际表现讨论新的片头结构。

## 方案选择

采用“每期配音显式传入、固定素材可选”的兼容方案：

- `--intro-voice` 指定本期片头话术配音。
- `--title-voice` 指定本期书名配音。
- `--voice` 继续指定正文配音，但正文从第一句故事开始，不再朗读书名。
- `--srt` 继续指定中文字幕，第一条改为第一句正文，不再包含书名。
- 固定素材按配置中的路径查找，存在则加入草稿，不存在则打印跳过提示。

不采用自动按文件名扫描，因为它可能误用上一期文件；不采用通用阶段配置器，因为当前 10 条验证期不需要这类复杂度。

## 新时间线

### 片头话术阶段

片头话术配音从 `0` 开始，片头话术的实际音频时长决定这一阶段的结束时间。

画面按以下优先级选择一种，避免多个片头画面串联后拖长开头：

1. 快闪目录内有图片时，将全部图片按文件名排序，并平均铺满片头话术时长。
2. 没有快闪图片但存在片头 MOV 时，从 `0` 开始播放 MOV；MOV 短于片头话术时，剩余时间使用全画幅书封补齐；MOV 长于片头话术时按片头话术结束点截断。
3. 两者都不存在时，直接使用全画幅书封铺满片头话术时长。

机械音效存在时从 `0` 开始，并在自身结束或片头话术结束时停止。片头 MOV 始终静音，避免与片头话术配音冲突。

### 书名阶段

片头话术结束后进入书名阶段：

- 全画幅书封开始或继续显示。
- 书名配音从该节点开始。
- 工作流自动生成 `《书名》` 中文字幕，开始和结束时间完全使用书名配音时长。
- 水滴音效存在时与书名阶段同步开始。

书名配音结束时间就是正文开始时间，不增加额外静默或固定等待。

### 正文阶段

正文配音、第一条正文字幕和第一张正文分镜在书名配音结束后同步开始。正文 SRT 的原始时间从 `00:00:00` 开始，所有正文字幕统一增加正文开始偏移。

正文开头音效存在时在正文开始节点播放。正文阶段继续保留书名、作者和缩小书封轨道。BGM 存在时从整条视频的 `0` 开始循环到视频结束。

## 素材规则

| 素材 | 来源 | 要求 | 缺失行为 |
|---|---|---|---|
| 片头话术配音 | 每期 `--intro-voice` | 必需 | 准备阶段停止并报明确错误 |
| 书名配音 | 每期 `--title-voice` | 必需 | 准备阶段停止并报明确错误 |
| 正文配音 | 每期 `--voice` | 必需 | 准备阶段停止并报明确错误 |
| 中文字幕 | 每期 `--srt` | 必需 | 空字幕或第一条仍为书名时停止 |
| 英文字幕 | 每期 `--srt-en` | 按现有配置决定 | 沿用中文字幕时间线；`--no-english` 可取消 |
| 书封 | Obsidian 或 `--cover` | 必需 | 沿用现有错误处理 |
| 快闪图片 | 固定素材目录 | 可选 | 改用片头 MOV 或全画幅书封 |
| 片头 MOV | 固定素材目录 | 可选 | 改用快闪图片或全画幅书封 |
| BGM | 固定素材目录 | 可选 | 不创建 BGM 轨道 |
| 机械音效 | 固定素材目录 | 可选 | 不创建对应音效片段 |
| 水滴音效 | 固定素材目录 | 可选 | 不创建对应音效片段 |
| 正文开头音效 | 固定素材目录 | 可选 | 不创建对应音效片段 |

配置中保留现有固定素材文件名，便于用户以后把同名素材放回目录即可自动启用。可选文件不存在时只输出一次清晰提示，不创建无效占位文件。

## 项目数据与兼容

新准备的项目写入 `workflow.json` schema v3，并将三段音频复制到当期目录：

```text
episodes/<项目名>/input/
  intro-voice.mp3
  title-voice.mp3
  body-voiceover.mp3
  body-subtitles.srt
```

schema v3 保存已经计算完成的片头结束、书名开始、正文开始和总时长，同时记录实际启用的可选素材。草稿生成阶段读取这些结果，不重复推导另一套时间线。

旧 schema v2 项目仍按原规则读取：正文音频和第一条 SRT 包含书名，固定片头素材保持原行为。新逻辑不得改变已经准备完成的旧项目。

## 代码边界

新增一个专门的时间线/素材规划模块，负责：

- 安全解析可选固定素材，返回存在的绝对路径或空值。
- 收集并排序快闪图片。
- 根据三段音频时长计算 schema v3 时间线。
- 生成只包含实际素材的轨道说明和源文件列表。

`prepare-jianying-workflow.mjs` 负责校验每期输入、复制文件、调用规划模块并写入 manifest。`create-jianying-draft.mjs` 负责按 manifest 添加存在的媒体轨道；它不自行猜测缺失素材，也不重新定义时间节点。

## 错误处理

- 两段开头配音或正文配音不存在、无法被 FFprobe 读取或时长为零时，指出具体文件并停止。
- 正文 SRT 为空时停止。
- 正文 SRT 第一条规范化后仍等于目标书名时，提示删除书名条目并重新导出正文 SRT。
- 快闪目录不存在、目录为空或没有支持的图片时，视为没有快闪图片，不报错。
- 可选音效或 BGM 不存在时打印跳过提示；文件存在但媒体损坏时停止，避免生成表面成功但无法播放的草稿。
- `draft-plan.json` 的轨道列表和 `sourceFiles` 仅包含实际启用的素材，不包含空字符串或不存在路径。

## 测试与验收

测试先于实现，至少覆盖：

1. 快闪图片平均铺满片头话术时长。
2. 快闪缺失时使用片头 MOV，MOV 时长与片头话术不一致时正确截断或用封面补齐。
3. 快闪与 MOV 都缺失时使用全画幅书封。
4. 片头话术结束后书名配音和书名字幕同步，正文紧接书名结束点。
5. 正文第一条 SRT 从 `0` 开始并正确增加正文偏移。
6. 第一条正文字幕仍为书名时拒绝准备。
7. 任意组合的 BGM 和三类音效缺失时，草稿计划只包含实际轨道。
8. schema v2 项目仍按旧时间线执行。
9. `npm run check` 全部通过。
10. 使用一组最小测试媒体完成 `workflow:prepare` 和 `workflow:draft --dry-run`，确认输出不引用缺失文件。
