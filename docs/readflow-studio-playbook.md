# ReadFlow Studio 制作手册

本文是 Obsidian 阅读知识库到可编辑剪映草稿的唯一有效生产SOP。旧版 Whisper/HyperFrames 成片渲染文件只在本机保留，不进入公开仓库。

## 1. 一次性配置

1. 运行 `npm run init`，检查 Node.js 22+、FFmpeg 和 FFprobe。
2. 填写 `.readflow.local.json`：Obsidian 路径、固定素材目录、CapCut Mate 地址。
3. 运行 `npm run capcut:setup` 安装本地草稿服务，再用 `npm run capcut:start` 启动。
4. 第一次安装剪映草稿前，由用户明确提供剪映草稿库目录；不得自动扫描私人目录。

## 2. 文案阶段

1. 在 Obsidian 中确认书名、作者、版本、封面、个人划线和笔记。
2. 文案开头先给清晰价值和适用人群，随后用具体情景、动作和感受展开。
3. 避免空泛说教、机械排比、学术摘要和高位劝导。
4. 第一行必须是书名，书名也要进入正文朗读和SRT。
5. 在对话中完整展示一版文案，等待用户确认后再进入音频阶段。

## 3. 音频与字幕阶段

用户提供：

- 正文朗读 MP3。
- 从0开始的中文 SRT，第一条为书名。
- 与中文逐条对应的英文 SRT；如果用户不需要英文字幕，明确使用 `--no-english`。

中文 SRT 是唯一时间真源。英文 SRT 只读取文本，开始和结束时间会强制复制对应的中文时间，避免双语漂移。主流程不调用 Whisper。

## 4. 准备项目

运行：

```bash
npm run workflow:prepare -- \
  --book "书名" \
  --voice "/绝对路径/正文.mp3" \
  --srt "/绝对路径/中文字幕.srt" \
  --srt-en "/绝对路径/英文字幕.srt" \
  --aspect "3:4"
```

可选参数：

- `--author "作者"`：覆盖或补充 Obsidian 作者。
- `--cover "/本地封面.jpg"`：Obsidian 中缺少封面时使用已确认的本地文件或网址；同时提供作者。
- `--project "项目名"`：指定当期目录名。
- `--scene-cue-counts "5,6,5,5,5"`：手动指定每镜字幕数量，单镜必须在5～10条之间。
- `--no-english`：本期明确取消英文字幕。

程序会：

1. 从 Obsidian 获取原始封面，并生成保持原封面比例的目标画幅适配版本。
2. 检查第一条中文字幕是否为书名。
3. 将正文 MP3、中文 SRT、英文 SRT 和封面固定为当期输入。
4. 根据片头 MOV 实际时长、快闪长度和封面开始点计算字幕偏移。
5. 生成 `workflow.json`、`source-manifest.md`、`segments.json`、`storyboard.json`、`storyboard.md`、`image-prompts.json`、`edit-plan.md` 和 `review-notes.md`。
6. 当期清单使用相对路径，项目改名或移动后仍可读取。

## 5. 分镜与配图

- 第一条书名字幕不计入正文分镜，由全画幅封面承接。
- 正文每镜覆盖5～10条字幕，一镜一图；不足5条的整篇短正文允许合并为一镜。
- 分镜数量随正文长度变化，不固定为7张。
- `storyboard.md` 是画面与剪辑的唯一时间真源，确认前不生成图片。
- 六种风格按项目稳定轮换：情绪化电影写实、极简自然、炭笔素描、扁平治愈、克制超现实、雕塑光影。
- 人物只允许远景、背影或剪影，面积不超过10%；禁止真人近景和清晰五官。
- 图片不含文字、卡片、水印、机甲、战争、血腥和夸张史诗效果。
- 图片按目标画幅生成，文件名为 `scene-001.png`、`scene-002.png`……

## 6. 精确时间线

| 阶段 | 画面 | 声音 | 字幕/文字 |
|---|---|---|---|
| 片头 MOV | `今天我们要分享的是.mov` | 片头语音 | 不显示字幕 |
| 快闪 | 固定快闪图片 | 机械音效从快闪开始 | 无片头字幕 |
| 书名揭示 | 全画幅书封，水滴遮罩入场 | 完整水滴音效；正文 MP3 开始 | 第一条中英文书名字幕 |
| 正文第一句 | 第一张分镜图；小封面点开 | 正文开头音效 | 书名、作者开始常驻 |
| 后续正文 | 每镜一张图，慢推近 | 正文旁白+BGM | 中英文逐条字幕 |

书名和作者从书名朗读结束后持续到视频结束。水滴音效允许延续进入正文，不按旧片头结束点强行截断。

## 7. 画幅与排版

| 画幅 | 分辨率 | 用途 |
|---|---:|---|
| 3:4 | 720×960 | 默认读书视频 |
| 9:16 | 1080×1920 | 竖屏平台 |
| 4:3 | 960×720 | 横向或复古构图 |

排版使用画布高度比例换算：书名约49%、作者约36%、中文约-38%、英文约-50%。英文默认字号5。切换画幅后必须检查标题与正文、中文与英文之间没有拥挤。

## 8. 生成剪映草稿

图片齐全后先干跑：

```bash
npm run workflow:draft -- --project "项目名" --dry-run
```

正式安装：

```bash
npm run workflow:draft -- \
  --project "项目名" \
  --install-to-jianying \
  --jianying-dir "/剪映草稿库目录" \
  --draft-name "草稿名称"
```

轨道结构：

- 视频：片头 MOV、快闪、全画幅封面、正文分镜、小封面。
- 音频：正文旁白、BGM、片头语音、机械音效、水滴音效、正文开头音效。
- 文字：中文、英文、书名、作者、昵称、来源说明。

安装时将媒体复制到草稿自身 `assets/`，并重写草稿内绝对路径。目标草稿已存在时停止，不覆盖旧草稿。

## 9. QA与交付

1. 运行 `npm run check`。
2. 检查草稿画布、总时长和所有源媒体时长。
3. 检查片头无字幕，机械、水滴、正文开头音效节点正确。
4. 检查书名揭示时存在正文人声，不以机械音效代替书名。
5. 检查中英文条数、时间、字号和上下间距。
6. 检查书名、作者常驻时间和位置。
7. 检查图片数量与分镜一致、无黑帧、无拉伸。
8. 检查剪映草稿内所有媒体路径指向草稿自己的 `assets/`。
9. 提醒用户完全退出并重新打开剪映，再预览和导出。

## 10. 每期目录

```text
episodes/<日期-书名>/
  workflow.json
  source-manifest.md
  storyboard.md
  edit-plan.md
  review-notes.md
  input/
    body-voiceover.mp3
    body-subtitles.srt
    body-subtitles-en.srt
    book-cover.jpg
    book-cover-full-3x4.jpg
  generated/
    segments.json
    shifted-captions.json
    shifted-captions-en.json
    storyboard.json
    image-prompts.json
  images/
    scene-001.png
    scene-002.png
```

每本书建立独立当期目录的目的只是防止素材重名和时间线互相覆盖，不复制核心代码和固定模板。
